# LyricSync

노래 커버 영상 제작자를 위한 자막 자동 생성 도구입니다.

## 문제 인식

기존 Whisper 기반 자막 도구들은 일반 발화에 최적화되어 있어
노래 커버 영상에서 정확도가 낮습니다.
가사를 이미 알고 있는 상황임에도 처음부터 받아쓰기를 시도하기 때문입니다.

## 해결 방법

가사 txt 파일을 힌트로 제공하면, WhisperX의 forced alignment로
실제 발화 타임스탬프와 가사를 정확하게 매칭합니다.

## 사용법

입력: 노래 영상 파일 + 가사 txt 파일  
출력: 타임스탬프가 정렬된 SRT 자막 파일

## 주요 기능

- WhisperX 기반 단어 단위 타임스탬프 추출
- 가사 txt와 forced alignment 매칭
- Gradio 기반 보정 UI (시간/텍스트 직접 수정)
- SRT 내보내기 및 Vrew, Premiere Pro 호환
